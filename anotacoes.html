Caixas

Uma caixa é o espaço que um elemento ocupa. É possivel utilizar caixas para guardar outras caixas, essa relação parecida com uma boneca russa é chamada de aninhamento. Propriedades de uma caixa:

  1. height - altura
  2. width - largura
  3. border - borda
  4. padding - preenchimento (espaço da borda até o conteudo)
  5. margin - margem (espaço da borda pra fora)
  6. outline - contorno (espaço em seguida da borda)

Existem 2 tipos de borda:


Box-level -> Sempre vai começar uma nova linha e vai ocupar a largural total do elemento onde ele está contido ou do body. Exemplo: div, h1-h6,p,video

Inline-level -> Não vai começar em uma nova linha (começara no ponto que for definido) e a largura vai ocupar o tamanho relativo ao conteúdo. Exemplo: span,a,strong,em

Para que a margem fique automaticamente no centro vertical, podemos usar margin:auto;

Grouping Tags e Semantic Tags

Antes do HTML 5 só existiam 2 tags de agrupamento: div (block-level) e span (inline-level). Entretanto, com a chegada do HTML 5 surgiram as tags semânticas de agrupamento, são elas:

  1. Header - Cabeçalho
  2. Nav - Área que possui os links de navegação pela estrutura da página (pode estar dentro da header)
  3. Main - Conteudo principal do site
  4. Footer - Rodapé
  5. Section - Seções de conteúdo (pode ficar dentro da main)
  6. Article - Conteúdo que pode ser lido independente (blog, fórum, notícia,etc...)
  7. Aside - Conteúdo periférico e completar

Vértices arredondadas

Podemos deixar as vértices de uma caixa arrendoda através do "border-radius". Podemos adicionar apenas um valor que servirá para os 4 cantos ou definir 4 valores para cada canto.

Bordas Personalizadas

Também é possivel importar bordas. Basta utilizar "border-image-source" e indicar o caminho para a imagem da borda, é preciso existir um "border" para alocar espaço. Existem alguns comandos que auxiliam na configuração dessa borda personalizada, são eles: "border-image-slice" e "border-image-repeat". O repeat pode ser stretch (arrasta a imagem de acordo com o tamanho do conteúdo) ou repeat (repete a imagem de acordo com o tamanho do conteúdo). O slice serve para indicar como a imagem deve ser recortada para definir a borda.

Variáveis em CSS

Podemos definir variáveis em CSS para facilitar, exemplo: invés de repetir o código de uma cor, podemos definir uma variável como cor principal que contenha o código da cor. Para isso, devemos utilizar a pseudo-classe ":root{}" e declarar dentro dela as nossa variáveis. Para declarar usamos a seguinte notação "--nome:valor;". Exemplo:

:root {
--cor0: #siw828
--cor-1:#2fa868
}

Seleção global

Uma forma de selecionar todos os elementos no CSS é utilizar *{}, dessa forma conseguimos fazer configurações "globais".

Responsividade para sites

Para trabalhar com largura e altura adaptáveis, utilizaremos tamanhos mínimos e máximos. Dessa forma, podemos definir uma tamanho máximo para que o conteúdo não fique esticado em telas grandes e tamanho mínimos para que o conteúdo não fique minúsculo.

  • min-width
  • max-width

Para imagens vamos utilizar "picture" e adicionar diferentes "source" dentro dele, assim é possivel ter imagens de diferentes tamanhos para telas diferentes. Exemplo:

<picture>
<source media="(max-width: 800px)" srcset="fotopequena.jpg">
<img src="foto.jpg" alt = "foto">
<picture>

Imagens de fundo

Para adicionar imagens de fundo vamos utilizar a mesma função que usamos para degrade: "background-image:". Porém, vamos utilizar dentro dela uma nova função: "url()" e dentro dessa função colocaremos o endereço para nossa imagem de fundo. Veja o exemplo abaixo

div{
  background-image: url(imagens/endereco)
}

Além disso, existem mais alguma configurações possíveis:

  1. "background-size: ---px (largura) ---px (altura)" - define o tamanho da imagem. Aceita também: contain (garante que a imagem seja 100% exibida, mesmo que isso gere barras) e cover (corta a imagem para que caiba)
  2. "background-repeat:" - define a repetição da imagem, aceita: repeat (repetição padrão do background image), no-repeat (sem repetição), repeat-x (repeticão no eixo x) e repeat-y (repetição no eixo y)
  3. "background-position: ---- ----" define a posição do fundo, aceita: left, right, center, bottom e top para representar a posição
  4. "background-attachment" define o vínculo do fundo em relação ao conteúdo. Por padrão vem como "scroll" (fundo rola junto com o conteúdo), mas também é aceito fixed (fundo fixo)

Além disso existe o shorthand "background", a ordem é: color > image > position > repeat > attachment. O background-size deve ser definido fora do shorthand.

IMPORTANTE!! é recomendado que se defina uma cor de fundo, mesmo que o fundo seja uma imagem, pois a imagem pode demorar para ser carregada

Alinhamento vertical

Para alinhar um elemento dentro de uma caixa, devemos seguir alguns passos:

  1. Definir a posição da caixa externa e do conteúdo. A caixa externa deve ter "position:relative" e o conteúdo deve ter "position:absolute"
  2. Agora que há a definição das posições, podemos definir um posicionamento para o conteúdo por ele ter position:absolute, então vamos definir "left:50%" e "top:50%".
  3. Você vai notar que o conteúdo não ficou centralizado, isso se dá porque a centralizão ocorrida foi do canto superior esquerdo e não do centro do conteúdo. Para centralizar seu centro vamos ter que fazer uma "tradução", basta usar transform: translate(-50%,-50%). Assim, o centro do conteúdo será centralizado no centro da caixa.

É importante citar que o transform: translate(0,0) pode ser usado para movimentar o objeto dentro da caixa. O primeiro valor se refere a esquerda se for negativo e a direita se for positivo, o segundo se refere a cima se for negativo e a baixo se for negativo.

Tabelas

Não se usa tabela para criar estrutura do site. As tabelas seguem hieraquias, veja:
Tabela Simples
table = tabela
  tr -table row = linha de tabela
  th - table header = cabeçalho de tabela
  td - table data = dado de tabela

Um recurso útil é o border-collapse. É possivel definir o alinhamento horizontal com o text aling e o vertical com vertical-aling

Hieraquia para tabelas grandes:
table
  thead - pode ter tr,td,th
  tbody - pode ter tr,td,th
  tfoot - pode ter tr,td, th

Para definir um titulo as tabelas é possivel usar a tag "caption". Também é importante definir um escopo para as tabelas, mesmo que não gere mudanças visuais, é feito para melhor visibilidade dos mecanismo de busca. O "scope" pode assumir os seguintes valores: col (toda a coluna abaixo), row (toda a linha a direita), colgroup (se refere a um grupo de colunas) ou rowgroup (se refere a um grupo de linhas)

Outro recurso que pode ser usado para tabelas e até além é a pseudo-classe ":nth-child()". Ao colocar um valor como ":nth-child(2n)",essa pseudo-classe vai repetir os efeitos de 2 em 2 "filhos". Um de seus usos em tabela é o efeito "zebrado". Além de valores, também é possivel usar par (even) ou impar (odd)

Apesar de ser um recurso que não funciona em todos os navegadores, é possivel fixar o cabeçalho de tabelas muito grande, o passo a passo é: 1. Definir a position da tabela como relative 2. Definir o position do cabeçalho como sticky e top: -1px 3. Caso o cabeçalho tenha um background, é preciso redefinir

Mesclagem de tabelas

Para expardir celulas horizontalmente ou verticalmente, vamos usar "<td colspan= x>" sendo x o número de colunas que queremos mesclar ou <td rowspan= x> sendo x o número de linhas que queremos mesclar
