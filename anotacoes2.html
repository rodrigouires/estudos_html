Iframe

Iframe é um "quadro em linha". Permite exibir uma janela de outro site no seu site. Alguns sites ou até navegadores bloquem o Iframe, caso o navegador bloqueie (principalmente os de celulares), é recomendado botar o link entre o >< do Iframe, assim o link será mostrado caso não tenha compatibilidade com o Iframe. O tamanho padrão de um Iframe é 300x150

É possivel utilizar um Iframe para abrir diferentes links de acordo com a opção do usuario, basta dar um "name:..." dentro de sua tag e preencer o "taget:..." do link com o nome escolhido. O problema é que dessa forma, o iframe fica "vazio" até que o conteúdo seja escolhido. Para contornar isso, existem 2 soluções: definir por padrão uma url que ele deve mostrar até que a escolha seja feita ou utilizar srcdoc="..." para digitar o código HTML dentro do próprio iframe.

Iframe não é muito recomendado para conteúdos importantes para o site, possibilidade de falhas. Além disso, outra problema pode ser a segurança, ao incluir um site terceiro no seu próprio site, você pode estar submetendo seus usuários a sites perigosos. Uma das formas de proteção é adicionar "sandbox="sandbox"" dentro da tag do iframe, assim não será possivel que terceiros coletem dados através de formulários, existem outras opções de sandbox também. Outra forma é adicionar "referrerpolicy="no-referrer"" para que o site terceiro não capture dados para fins de propaganda.

Através de iframes é possivel adicionar vídeos, mapas, apresentações de slides Google,etc..

Animações

Uma das formas de fazer animação é usando o "transition: tag_escolhida ...segundos".Exemplo: transition: border 3s -> A borda irá aparecer em 3 segundos, o interessante é usar no :hover.

Formulários

Todas as partes de um formulários devem estar entre as tag <form>. É preciso definir o action="..." para indicar para qual arquivo back-end devem ir esses dados.
Todos as caixas que vão recolher informações deve estar com tag <input>, sendo necessário definir o seu type e name. O name é importante para linguagens back-end e para o HTML, o id é importante para o Javascript. Além disso, é necessário definir um label que se relaciona ao id. Veja o exemplo abaixo:

<form action="arquivo_back_end.php">
<p><label for="inome">Nome: </label>
<input type="text" name ="nome" id="inome"></p>

Caso deseje desativar o auto-completar basta inserir "autocomplete="off" dentro da tag.
